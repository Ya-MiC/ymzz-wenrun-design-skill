# 02 · 表面、字體與數字——溫潤質感的物理基礎

> 所有規則標註狀態：【鐵律】（用戶明確指定，不可動）／【規範】（有依據的本產品規則）／【偏好】（設計選擇，可討論）。

## 1. 表面明度階（surface-0 ~ 3）【鐵律】

分層靠**明度差**，不畫 1px 邊框。四級表面：

| 層級 | 淺色模式 | 深色模式 | 語義 |
|---|---|---|---|
| surface-0 | `--bg-0`（暖紙白/暖黑） | 同左 | 頁面最底 |
| surface-1 | 白 62% 疊加 | `#2A241D` | 卡片 |
| surface-2 | 白 80% | `#352E25` | 浮起卡片、hover 態 |
| surface-3 | 白 95% + 陰影 | `#423A2F` | 浮層、popover |

規則：
- 相鄰兩級明度差至少 4%，確保任何顯示器上可辨識。
- 疊加一律用 `rgba` 疊於上一級之上，禁止為「表現層級」引入新色相。
- 每級只配一個陰影檔位（見第 3 節），禁止邊框 + 陰影同時上。

## 2. 字重與變量字體【鐵律】

1. **暗色模式字重整體 −40**：變量字體 `wght` 軸在深色主題下全部減 40（例如 500 → 460）。原因：深底淺字有光暈效應（halation），視覺字重會「變胖」，減 40 恢復觀感平衡。實現：
   ```css
   [data-theme="dark"] { --wght-shift: -40; }
   /* 字級 token 中：font-variation-settings: "wght" calc(var(--w-500) + var(--wght-shift)); */
   ```
   前提：字體必須是變量字體（Noto Sans SC Variable 等，SIL OFL 授權，可商用可嵌入）。若降級到靜態字重字體，深色模式就近取一檔（500→400），並記錄偏差。
2. **`font-variant-numeric: tabular-nums`【鐵律】**：所有數字——表格、統計、時間、金額、進度——等寬鎖死。任何數字會變化的地方（計時器、流式輸出的 token 計數）不鎖 tabular-nums 就會抖動。這是全域規則，寫在 `:root`。
3. `text-wrap: pretty`【鐵律】：正文段落排版保護，避免孤行寡字。配合 `text-wrap: balance` 用於標題（≤3 行的標題平衡斷行）。
4. 行內小圖標【鐵律】：`svg { vertical-align: -0.125em }`（1/8 em），圖標不漂、不頂線。
5. 字階【規範，桌面基準，移動端須另行驗證】：14 正文 / 13 次級 / 12 輔助 / 20 小標 / 28 頁標。移動端正文不低於 14px，長文閱讀 15–16px。**此階是桌面表格型產品預設，不是物理法則**；大字號輔助功能（系統字體縮放）必須全量測試。

## 3. 模糊與陰影【鐵律 + 規範】

1. **`blur(6px)`【鐵律】**：毛玻璃表面（backdrop-filter）統一 6px，不大於不大於。溫潤感來源之一：邊界融掉但不糊掉。
2. 陰影體系【規範】：
   - 鍵盤光暈（按下/聚焦）：`0 0 0 3px` 半透明強調色，不位移。
   - 浮起陰影：`0 8px 24px rgba(61,56,51,.10)`（暖灰黑，不用冷黑）。
   - 浮層陰影：`0 16px 48px rgba(61,56,51,.16)`。
   - **輸入框咬合感【鐵律】**：外陰影 + inset 內環一起上——`box-shadow: 0 1px 2px rgba(61,56,51,.08), inset 0 1px 2px rgba(61,56,51,.06)`。外柔內沉，是「溫潤咬合」的關鍵手感。
3. 同心圓角【規範】：外圓角 = 內圓角 + 內距（如外 16px、padding 8px、內 8px）。這是嵌套等距時的幾何參考，不是強制定理；不等距嵌套按視覺微調並記錄。
4. 陰影裁切安全距【規範】：容器為陰影預留 `offsetY + blur` 的估算空間（多層陰影取最大者）。**此為估算不是保證**；負偏移、水平大位移場景必須實測。

## 4. 質感硬參數匯總（用戶原話逐條入冊）

| 參數 | 值 | 出處 |
|---|---|---|
| surface 層級 | 0~3 | 用戶 |
| 深色字重偏移 | wght −40 | 用戶 |
| 數字 | tabular-nums 全域 | 用戶 |
| 毛玻璃 | blur(6px) | 用戶 |
| 排版保護 | text-wrap: pretty | 用戶 |
| 行內圖標 | vertical-align: −0.125em | 用戶 |
| 輸入框 | 外陰影 + inset 內環 | 用戶 |
| 分隔 | 明度階，不畫 1px 邊框 | 用戶 |
| 彈簧剛度 | stiffness: 1200（吸附類） | 用戶 |
| 流式輸出 | 逐字 blur 暈開，見 05 | 用戶 |

## 5. 實現注意（紅藍對抗教訓）

- `text-wrap: pretty` 在 WebKitGTK（Linux）上支持不完整：降級為普通換行即可，不做 JS polyfill。
- `backdrop-filter` 在 Android 低端 WebView 有性能風險：surface-3 以上的毛玻璃元素在同一視口內不超過 2 個，超出的降級為實色。
- 變量字體子集化後再加載，避免全字庫 10MB+ 拖慢首屏。
