# 01 · 色彩提示詞（疊加在 00 之上）

寫任何涉及顏色的代碼前，先聲明：「四色封頂，八值鎖定」。

## 色卡常量（唯一允許的色值來源）

雲箋（淺主題基底）：#F8F6EF 暖紙白 / #B9DDF1 淺天空藍（標籤、手繪裝飾）/ #F4DDE7 荷花粉（輕柔點綴、重點提示）/ #CDBFE0 淡紫（過渡、聚焦光暈）
暮靄（雲箋莫蘭迪深版）：#E6E1D5 / #7C9DB5 / #B394A3 / #93879F
陶土（溫暖內容主題）：#E8E3CC / #b7c8a8 / #CBBF9E / #A38E7A
暮林（陶土莫蘭迪深版）：#D9D3C0 / #7E8E6F / #9E9073 / #7C6B59

## 執行規則

1. 組件裡只准寫 `var(--*)`，不准出現新的 hex。
2. 正文、次級文字、佔位、禁用一律 `--ink-1/2/3`；遮罩 `--scrim`；分隔用 `--line-1` 低透明度，不畫 1px 實線。
3. 同一畫面不混兩套淺色系；分區使用需聲明。
4. 需要新語義色（成功/警告/危險）時：從當前色系四色內映射（成功→鼠尾草綠/苔蘚綠，提示→淺天空藍/霧靄藍，重點→荷花粉/乾藕粉），不夠用時停下來問，不許自造色。
5. 深色模式：`[data-theme="dark"]` 切換全部變量；字重偏移 −40 一起切。
6. 標籤 = 四色底 + `--ink-1` 文字，檢查對比後交付。
