# 09 · 驗收清單——可執行的紅隊測試

> 上一版被紅藍對抗指出「檢查清單只問有沒有照規則做，不問規則本身會不會錯」。本清單分兩部分：A 合規檢查（照規則做），B 對抗測試（攻擊規則本身）。全部手動可執行，CI 能自動化的標【CI】。

## A. 合規檢查

### 色彩
- [ ] 全項目 grep 十六進制色值：只出現 tokens.css 中定義的變量【CI】
- [ ] 四套色卡各恰好四色；八個原始值與本文檔逐字符對
- [ ] 正文只有 `--ink-*`；無「四色直接當正文」實例
- [ ] 深淺主題切換後逐屏截圖存檔

### 表面與字體
- [ ] 變量字體生效，深色模式 `wght` 整體 −40 實測
- [ ] 所有數字容器 `tabular-nums`（計時器/表格/金額抽查）【CI：樣式表靜態檢查】
- [ ] 無 1px 實線分層（明度階承擔）【CI】
- [ ] 輸入框 = 外陰影 + inset 內環，逐個輸入框截圖

### 熱區
- [ ] 逐個可點元素測命中區 ≥48×48（DevTools 覆蓋層可視化截圖）
- [ ] 外擴熱區逐對檢查無重疊
- [ ] 同目的地組合（頭像+名字）是單一連續熱區（事件監聽驗證）

### 浮層
- [ ] 每個浮層：開啟焦點入內、Esc/返回鍵/遮罩/關閉鈕四路徑齊、關閉焦點返回
- [ ] 髒資料守衛：五條關閉路徑全部觸發確認（不是只禁遮罩）
- [ ] 退出動畫期間點底層元素——必須無響應（重點回歸上一版 pointer-events 錯誤）
- [ ] 多層浮層嵌套：先開 A 再開 B，關 B 不解鎖 A 的滾動

### 動效
- [ ] `prefers-reduced-motion` 下逐字暈開關閉
- [ ] 展開用 `grid-template-rows` 0fr→1fr，無 JS 測高【CI：代碼審查】
- [ ] 拖拽吸附 ≤200ms 無過衝；點贊有 1–2 次過衝

## B. 對抗測試（攻擊規則本身）

- [ ] **退出中穿透**：浮層淡出 250ms 內狂點底層「刪除」——零穿透
- [ ] **抽屜套抽屜**：Drawer 裡開 Modal 裡開 PopConfirm，逐層關閉、逐層焦點正確
- [ ] **手機接滑鼠**：Android 平板接藍牙滑鼠——hover 與熱區行為合理
- [ ] **系統字體放大 200%**： iOS/Android 系統字級最大——無截斷、無重疊、熱區不縮水
- [ ] **鍵盤彈出時轉橫屏**：輸入一半旋轉——焦點保持、不重複滾動
- [ ] **混淆途中殺進程**（若做構建任務）：恢復後狀態明確，無半成品文件冒充成品
- [ ] **斷網時帳號畫面**：登入請求超時文案誠實；本地鎖完全不依賴網路
- [ ] **1GB 惡意文件**：拖入超大/改擴展名文件——被拒絕且提示明確，不卡死
- [ ] **Linux 最弱引擎**：WebKitGTK 上 `text-wrap:pretty`、grid 過渡、backdrop-filter 逐項降級正常
- [ ] **Windows 150% DPI**：無模糊、熱區對齊
- [ ] **連續快速開關**：10 秒內開關同一 Modal 20 次——無殭屍遮罩、無滾動鎖泄漏
- [ ] **深淺主題熱切換**：動畫進行中切主題——無閃爍、無色彩殘留

## C. 成熟度聲明（防「假完成感」）

本包交付的是：**設計系統文檔 + 提示詞集 + 連結庫 + 可運行 Tauri 骨架（登入 UI + 主界面殼）**。
本包**不是**：完整商業應用、經過五平台實測的成品、無障礙認證產品。
以下必須由你在真機完成後才能聲稱「已實現」：五平台簽名分發、生物識別接入、對比度真機實測、100 條對抗測試全綠。
