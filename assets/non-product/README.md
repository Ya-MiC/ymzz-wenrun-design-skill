# Not the product palette

`vibe-content.css` is copied verbatim from `tokens/vibe-content.css` in wenrun-design-system v7.1.

It is a sticker preset for marketing and guide art. The archive forbids loading it in ordinary product components. It is not a 雲箋 color, not a 陶土 color, and not an Office theme.

Its colors include `#ECE9E2`, `#E8443A`, `#F5B301`, `#2B50C8`, and `#111111`. None of those belong on the color card.

The file's own header says the look was summarized from Ludi video frames. The frames and transcripts are not included. This CSS is the user's token file, not those videos.
