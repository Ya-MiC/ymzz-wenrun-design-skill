# Token source

`tokens.css` is the machine-readable color and measure file from wenrun-design-system v7.1. It is copied verbatim.

`contrast-matrix.md` and `motion.js` are also verbatim.

`index.derived.json` is generated by `scripts/validate_wenrun.py` from `tokens.css`. The v7.1 archive did not contain `tokens.json` or `tokens.light.json`. Do not treat the derived index as either of those files.

The whitepaper tells a future edit to sync `tokens.light.json` after 深藤紫 is confirmed. That confirmation is still open, and the file was not in the archive.
